# Starbucks Homepage Pull Request Practice

這是一個 HTML／CSS 與 GitHub Pull Request 練習專案。頁面已提供基本結構，請從下列任務選一項完成。

## 練習流程

1. 點右上角 **Fork**，把專案複製到自己的 GitHub。
2. Clone 自己 Fork 的 Repository。
3. 建立 Branch：`git switch -c feature/你的任務名稱`。
4. 完成一項任務，確認桌面版與手機版畫面。
5. 建立清楚的 Commit 並 Push。
6. 從自己的 Repository 對本專案的 `main` 發 Pull Request。

## 任務（三選一）

- `feature/mobile-menu`：讓手機版 Navbar 隱藏選項並顯示 MENU 按鈕。
- `feature/rewards-card`：新增一張 Rewards 介紹卡片，維持既有版型。
- `fix/card-responsive`：讓 `.feature-card` 在 768px 以下改成上下排列。

## Pull Request 要包含

- 清楚的標題，例如 `feat: add rewards card`
- 修改內容摘要
- 測試方式
- 桌面版與手機版截圖

請勿直接修改原始 Repository 的 `main`；所有作業都透過 Fork 與 Pull Request 提交。
